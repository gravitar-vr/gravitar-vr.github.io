# Gravitar VR

[Play Gravitar VR](https://gravitar-vr.github.io/) in Meta Quest Browser.

Press **CLICK TO ENTER VR**, accept the VR prompt, then press any controller button except left grip to start from attract. No downloads, PC connection, installation or command-line setup are required.

This repository contains the built website and required notices only.

For high-score initials, scroll with the left stick and confirm each letter with any right-hand button. Left grip always recentres. Start is disabled during initials entry.
